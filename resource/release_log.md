## ✨ 新功能

### 🎙️ Qwen 引擎接入
- 全新接入 Qwen 引擎，支持同传 / 字幕 / 打字翻译三合一
- 内置完整的 Qwen 多语种语音音色库，并扩展可选 TTS 音色
- 音色选择器升级为「全部 / 同传音色 / TTS 音色」三态筛选

### 🔥 热词系统
- 新增热词管理系统，支持自定义术语库
- 内置常见游戏热词包：
  - Apex Legends
  - CS2
  - PUBG
  - ARC Raiders
  - 三角洲行动
  - 太空杀
  - 无畏契约
  - 鹅鸭杀
- 支持中英 / 中俄 / 英中 / 俄中多向热词配置

### 🎚️ 高级音频面板
- 新增「高级」开关按钮，默认隐藏虚拟麦克风和音频源行，界面更清爽
- 首次点击高级按钮时弹出说明引导，并支持勾选「不再显示」
- 中 → 中场景新增提示弹窗，Typed 同语言时自动跳过翻译

### 🎨 UI / 资源优化
- 内置 MiSans 字体（Regular / Bold）
- 优化反馈窗口 UI
- 统一语言选择器为 LangPicker 组件

## 🐛 修复
- 修复 Qwen 同传译文丢字、字幕覆盖丢段、输出设备启动异常等问题
- 修复软件启动时自动弹出提示窗的问题
- 字幕保留更多历史行，避免闪入闪出导致无法核对翻译
- 默认隐藏虚拟回环输入麦克风，启动同传前拦截错误设备，避免自反馈闭环
- 无前次选择时自动选择 CABLE Input 作为默认输出

- 新增设置项 `show_advanced_panel`（默认 `False`）
