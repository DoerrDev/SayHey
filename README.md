# SayHey

![SayHey](resource/brand-banner.png)

中文说明 | [English](README_EN.md)

SayHey 是一个 Windows 桌面实时语音翻译工具，适合游戏语音沟通、外语直播字幕、跨语言会议等场景。

主界面预览：

![主界面](resource/MainPannel.png)

## 主要能力

- **同声传译**：采集你的麦克风，把你说的话实时翻译并通过虚拟声卡输出，让队友/对方在游戏或语音软件里听到翻译后的声音。
- **游戏字幕**：捕获系统扬声器输出，把游戏 / 视频 / 通话里的外语实时翻译成悬浮字幕显示在屏幕上。
- **打字翻译**：直接打字输入，实时翻译并以语音合成播放到虚拟麦克风，不开口也能"说"外语。

## 先下载使用

如果你只想直接体验，不需要看代码：

1. 打开本仓库的 `Releases` 页面。
2. 下载最新的 Windows 压缩包。
3. 解压后直接运行 `sayhey.exe`。
4. 首次启动可使用内置试用额度，或在右上角设置中填入你自己的火山引擎 / Qwen Key（填入自己的 Key 后会自动取消试用代理）。
5. 应用内置**自动更新**，新版本会自动提示下载。
6. 遇到问题可点顶栏的 QQ 图标加交流群，或在反馈窗口点「发送错误日志」一键把运行日志发给开发者。

## 功能特性

### 翻译与字幕
- 实时麦克风同声传译（豆包 / Qwen 端到端语音大模型）
- 系统音频悬浮字幕（WASAPI loopback 捕获），保留多行历史避免闪烁
- 打字翻译 → 语音合成输出；同语言自动跳过翻译直接 TTS
- 翻译字幕可选是否同时显示原文
- **字幕过滤**：游戏字幕可勾选「不显示中文语音字幕」，只留下需要翻译的外语内容
- 多语言互译，统一 LangPicker 语言选择器
- 中→中等同语言场景自动提示，避免误操作
- 音色与语言不匹配时自动校验提示（同传音色 / 普通 TTS 音色不会混用）

### 麦克风模式
- **按住快捷键时翻译**（push-to-translate）：按住热键说话走翻译，松开时直接输出原声，方便中文队友和外语对手切换
- **耳返**：把翻译后的音频同时播放到自己的耳机，确认已翻译输出，不影响进游戏的声音
- **噪声门阈值**：低于阈值的输入直接静音不送识别，避免耳机漏音被当成队友语音翻译（默认 0.020，麦克风面板滑块可调）
- 启动时按当前配置自动切换到合适的默认模式

### 热词系统
- 自定义热词表，提升专有名词 / 人名 / 游戏术语识别准确率
- 内置常见游戏热词包，开箱即用（已精简大热词表，避免高延迟与额外推理成本）

### 语音定制
- 音色选择对话框：内置豆包 / Seed TTS 2.0 / Qwen 全系音色，可拖动悬浮预览
- 语速调节（-50 ~ +100，Qwen 引擎自动隐藏不支持的语速控制）
- 可保存翻译音频到本地

### 快捷键与悬浮提示
- 自定义全局快捷键系统
- 支持鼠标侧键（X1/X2）作为热键
- 麦克风一键开关、字幕一键开关、按住翻译热键
- 操作时屏幕上有悬浮提示

### 设备与音频
- 一键检测虚拟声卡（VB-Cable）链路
- 主界面「高级」开关，默认隐藏虚拟麦克风 / 音频源行，简化常用操作
- 麦克风列表默认隐藏虚拟回环设备，避免误选造成自反馈
- 启动同传前自动拦截错误的自反馈设备配置
- 首次未选择输出时自动选 CABLE Input
- 游戏字幕与同声传译共用虚拟线时自动避让

### 翻译历史与用量
- 翻译历史记录（原文 / 译文 / 时间）按天保存在本地，可在设置里按日期范围统计、导出 txt、删除
- 用量统计与计费（输入音频 / 输出文本 / 输出音频 token 累计），顶栏 chip 显示会话与累计费用，明细可按天/月聚合并导出 CSV，默认关闭

### 其它
- 内置试用代理（`trial.sayhey.top`），首次使用免配置 Key；试用渠道支持同声传译与游戏字幕同时使用
- 顶栏 QQ 交流群入口
- 反馈窗口支持「发送错误日志」，一键把运行日志整理发给开发者；反馈自动附带版本号并同步到 GitHub Issue
- 自动更新（GitHub / Gitee 双源）
- 内置 MiSans 字体，跨设备显示一致
- 运行日志面板，便于排查延迟和异常

## 引擎说明

底层支持两套实时大模型语音引擎，覆盖同传 / 字幕 / 打字翻译三条链路：

- **火山引擎（豆包）**：默认引擎，端到端实时语音
- **Qwen（阿里通义）**：可选引擎，提供额外音色与语言选择

使用方式：

- 首次使用：可直接用内置试用额度体验
- 长期使用：建议自备火山引擎或 Qwen Key

火山引擎控制台快捷入口：
https://console.volcengine.com/speech/new/overview?projectName=default

## 使用前准备

### 同声传译

- 建议安装 [VB-Cable](https://vb-audio.com/Cable/)
- 在目标游戏或语音软件里，把麦克风切换到 `CABLE Output`

默认音频链路：

```text
真实麦克风 -> SayHey -> CABLE Input -> CABLE Output -> 目标应用
```

### 游戏字幕

- 不需要 VB-Cable
- 通过 WASAPI loopback 捕获系统播放声音
- 可在主面板"音频源"中选择具体的扬声器 / 耳机

## 自己从源码运行

### 环境要求

- Windows 10/11
- Python 3.11 及以上

### 安装依赖

```powershell
python -m pip install -r requirements.txt
```

### 启动 GUI

```powershell
python main.py
```

首次运行时，如果没有 `settings.json`，程序会自动创建。也可以通过界面右上角设置页填写并保存配置。

配置文件位置：源码运行时在仓库根目录；打包为 exe 后与 `sayhey.exe` 同目录（早期版本会写入临时目录导致设置丢失，升级后请确认程序目录可写）。

### 查看本机音频设备

```powershell
python scripts\list_audio_devices.py
```

### CLI 示例

```powershell
python scripts\realtime_s2s_voice_demo.py
```

## 自己构建发布版

```powershell
build\build_nuitka.bat
```

构建完成后会在 `dist\` 下生成 Windows 可执行文件目录和 zip 包。打 tag（`v*`）推送到仓库会自动触发 CI 构建并发布到 GitHub / Gitee。

## 项目结构

- `main.py`：GUI 入口
- `gui/`：桌面界面、悬浮字幕、悬浮提示、设置、音色选择等
- `app_core/controller.py`：麦克风同声传译链路
- `app_core/game_subtitle_controller.py`：系统音频字幕链路
- `app_core/typed_controller.py`：打字翻译链路
- `app_core/audio_io.py` / `system_audio.py`：音频采集与 WASAPI loopback
- `core/hotkey.py`：全局快捷键 / 鼠标侧键 / 按住翻译
- `core/usage_tracker.py`：用量计费
- `core/history_store.py` + `gui/history_recorder.py`：翻译历史落盘与导出
- `core/update_checker.py`：自动更新
- `gui/feedback_dialog.py`：需求反馈与一键发送错误日志
- `scripts/`：命令行示例与诊断工具
